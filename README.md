В шаблоне созданы два элемента данных:

1. `CPU utilization` — мониторинг загрузки CPU в процентах.
2. `RAM utilization` — мониторинг использования оперативной памяти в процентах.

Для CPU используется ключ:

```text
system.cpu.util[all,user,avg1]
